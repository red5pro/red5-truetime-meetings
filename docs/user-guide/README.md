# User guide

This guide is for people who use TrueTime Meetings: joining calls, hosting them, recording them. You don't need
any technical knowledge.

All you need is a current browser (Chrome, Edge, Firefox or Safari) on a computer, phone or tablet, and a camera and
microphone if you want to be seen and heard. There is nothing to install.

| Guide                                                              | Read it to…                                                         |
| ------------------------------------------------------------------ | ------------------------------------------------------------------- |
| [Joining a meeting](joining-a-meeting.md)                          | Start a meeting, join one from a link, and get past the lobby       |
| [In a meeting](in-a-meeting.md)                                    | Use the control bar, chat, react, share your screen, change layout  |
| [Camera, microphone and effects](camera-microphone-and-effects.md) | Pick devices, blur your background, cut noise, fix a bad connection |
| [Recording and captions](recording-and-captions.md)                | Record a meeting, turn on captions, get a transcript                |
| [Hosting a meeting](hosting-a-meeting.md)                          | Run a meeting as the host: admit guests, remove people, add streams |

Some features (recording, captions, external streams and signing in) are only there if whoever runs your TrueTime
Meetings has turned them on. If a button is greyed out, that feature is off for your organization.

Something not working? See [Troubleshooting](../troubleshooting.md).
